# :truck: Stochastic Capacity Simulator

An interactive Monte-Carlo simulator for capacity modeling under stochastic demand, reliability, quality, and efficiency. Developed for **ISyE 6202 & 6335 — Supply Chain Facilities** at the Georgia Institute of Technology (Instructor: Prof. Benoit Montreuil). This is the web (HTML) version; a Python (Streamlit) version is also available.

- **Live app:** https://capacity-model.github.io/
- **Python (Streamlit) version:** https://github.com/capacity-model/capacity-simulator-python

## Built with

Plain **HTML, CSS, and JavaScript** in a single self-contained file (`index.html`) — no frameworks and no build step. The Monte-Carlo engine and all charts are hand-written.

## Usage

Simply open **https://capacity-model.github.io/** in any browser — nothing to install.

To run it locally, download `index.html` and open it directly, or serve the folder:

```bash
python -m http.server
```

Then visit http://localhost:8000.
